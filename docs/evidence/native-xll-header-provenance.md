## Interpretation, licensing and limits

- The SDK also contains `SRC/XLCALL.CPP` callback bridge, x86/x64 import libraries, `DOC/Excel14XLLSDK.chm`, samples, and project files. These are not extra headers. `tools/abi-check` is the repository’s separate ABI comparison tool, not an SDK authority. The bridge directly includes Windows and `xlcall.h`.
